Privacy

Last updated: 30 October 2026.

Short version

This site does not use cookies, analytics, advertising, external fonts or third-party scripts. Calculators run entirely in your browser: the numbers you type are not sent anywhere.

Hosting

The site is hosted on GitHub Pages. As with any web host, GitHub may process technical data such as your IP address when it serves a page, for example for security purposes. See the GitHub General Privacy Statement and the GitHub Pages documentation. Lumen & Ledger has no access to visitor logs.

Downloads

Spreadsheet templates are plain .xlsx files with no macros and no external connections.

Purchases

Paid guides are sold through Gumroad. Purchase links take you to gumroad.com, which handles payment and the related data under the Gumroad privacy policy. Lumen & Ledger receives only what Gumroad provides to sellers to fulfil an order.

Email

If you write to lumenledger.tools@proton.me, your message is used only to reply or to correct the content. There is no newsletter and no mailing list.

Changes

If this notice changes, the date above is updated.
